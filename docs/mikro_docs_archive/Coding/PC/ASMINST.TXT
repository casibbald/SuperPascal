ºOverview         Overview of the Instruction Format
º
º    Each entry in this list includes information on which flags in the
º    8088's flag register are changed, and how they're changed.  Since
º    there are 9 flags in the flags register, the flags display is very
º    compact:
º                        Flags: O D I T S Z A P C
º                               0       * * ? * 0
º
º           ?      Undefined after the operation.
º           *      Changed to reflect the results of the instruction.
º           0      Always cleared
º           1      Always set

º    these charts represent the worst case.

ºAAA
º          Logic:    If (AL & 0Fh) > 9 or (AF = 1) then
º                        AL  <-  AL + 6

º    BCD number (high-order nibble of AL is zeroed).
º  ÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄÄ

º    auxiliary carry flag is set, this instruction converts AL to its
